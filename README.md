## Selected Technical Highlights

- **Storage:** Verified an XFS filesystem mounted at `/archive` after reboot and checked persistent swap configuration.
- **Security:** Configured the permanent public firewall zone for HTTPS and tested HTTPS access versus blocked HTTP.
- **Containers:** Pulled a Red Hat UBI HTTPD image, verified a running Podman container, and tested its web service.
- **Automation:** Documented Bash scripting, cron scheduling, and Kickstart configuration validation.

## Documentation & Lab Scope
