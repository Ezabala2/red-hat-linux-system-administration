# Kali Linux Virtual Machine Setup and Verification

## Overview
This project documents a Kali Linux virtual machine running in VMware, supported by screenshots from an August 30, 2026 lab submission. It demonstrates hands-on familiarity with a virtualized Linux environment and basic terminal verification.

## Technologies
- VMware virtualization software
- Kali Linux
- Linux terminal

## Documented evidence
1. Host-side command-line / virtual machine environment screenshot.
2. Kali Linux graphical desktop displayed within VMware.
3. Kali Linux terminal displayed within the virtual machine.
4. Kali Linux terminal executing `date` to confirm the guest system is running.

## Skills demonstrated
- Operating a Linux guest in a virtual machine
- Using the Linux command-line interface
- Capturing system verification evidence

## Scope
This is a local virtualization lab, **not** an AWS, Azure, or Google Cloud deployment. The supplied screenshots establish operation of a Kali Linux VM; they do not independently document the full VM installation workflow or specific virtual network settings.
